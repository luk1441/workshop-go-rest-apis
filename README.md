# Workshop Go REST APIs
Study materials for following along with a workshop on building REST APIs in Go.

## Project Structure

### 1. [`setup/`](./setup)
This folder contains the **pre-workshop setup materials** and prerequisites.

### 2. [`exercises/`](./exercises)
This folder contains a series of **guided exercises** and example scripts designed to teach the fundamentals of Go.

### 3. [`project/`](./project/)
In this folder, you will build your **own small REST API**, applying everything you have learned during the workshop.

## Getting Started
Go to the [`setup`](./setup) folder and follow the instructions in [`installation.md`](./setup/installation.md).
